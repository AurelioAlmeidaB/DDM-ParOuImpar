# Par ou Ímpar

Jogo de par ou ímpar entre o usuário e o smartphone.

## O que o app faz

- O usuário escolhe uma mão de 0 a 5 dedos e se quer **par** ou **ímpar**; o smartphone fica com o contrário.
- Ao tocar em **Jogar**, o smartphone sorteia a mão dele, as duas mãos são somadas e o app mostra quem ganhou.
- Se o usuário tentar jogar sem escolher a mão ou par/ímpar, o app avisa.
